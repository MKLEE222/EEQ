## What would not surpass fully informed B9

- Starting a native Kubernetes WATCH from a collection LIST `metadata.resourceVersion` is the documented API semantics and client-go `Reflector` routine, including object add/update/delete delivery and 410/re-LIST recovery.
- A credential-independent detached JSON list of object digests is not authoritative evidence that no new source exists; original R3-M3 native experiment already killed this simplification, but fully informed B9 reproduces the fix.
- Deterministic decision certification across an incomplete possible-world class is a classical certain-answer computation. `Indeterminate` vs `Deny` under effect-specific policy combination is addressed by XACML; basic evidence three-valued decisions are not new.
- A conditional scoped proof whose VAP source-class inventory membership is supplied by the experiment author is not an externally established source-authority closure certificate.
- A list and a watch for two different Kubernetes kinds do NOT automatically establish a single atomic cross-kind cut. A WATCH prefix read before an arbitrary later request does not certify the absence of unseen *subsequent* events at wall-clock `NOW`.
- If B9 means all computable methods with identical sources and budgets, strict expressive dominance is impossible because B9 can copy EEQ. Comparisons must instead operationalize a genuinely distinct object or a fixed strong implementable alternative under realistic constraints.
